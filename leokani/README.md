# Leokani

Fast, local text to speech for Home Assistant, with the Leokani-tts 7M voice. Runs on the CPU, amd64 or aarch64,
including a Raspberry Pi 4 or 5.

[Leokani-tts 7M](https://huggingface.co/milliwattlabs/leokani-tts-7M) is from [Milliwatt Labs](https://milliwattlabs.com).
The voice is free for non-commercial use (CC BY-NC 4.0).
